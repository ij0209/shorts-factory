# 새벽한구절 운영 원칙

- 사람의 구체적 고민에서 시작하고, 문맥을 확인한 성경 본문을 고른 뒤 묵상과 기도를 쓴다.
- 성경은 출처, 번역본, 이용 조건, 정확한 원문을 기록한다. 영상에서 일부만 읽으면 발췌임을 데이터에 명시한다.
- 새 영상 전 전체 `history/content_history.json`과 기존 10편의 고민, 관점, Hook 의미, 구절, 묵상, 기도, 시각 콘셉트를 비교한다. 제목만 바꾼 재탕을 금지한다.
- 따뜻하고 또렷한 새벽 라디오 목소리를 지향하며 실제 오디오 길이와 발음을 검토한다.
- 최종 음성은 Gemini TTS를 사용한다. 로컬 TTS를 최종 영상에 쓰지 않는다. 중앙 자막은 삶의여백에 가까운 명조 계열을 크게 쓰고, 좌측 상단 채널명과 우측 하단 성경 장·절은 영상 내내 표시한다.
- 기본 공개 약속은 매일 05:00 Asia/Seoul이다. 채널 ID와 인증된 채널명이 새벽한구절로 확인되기 전에는 업로드하지 않는다.
- WeMakeVoice, 삶의여백의 콘텐츠, 이력, 토큰, 분석, 예약 데이터를 사용하거나 변경하지 않는다.
- 조회수 외에도 스와이프 대비 시청, 유지율, 재생률, 공유, 구독, 재방문 지표를 본다. 다음 라운드의 주제와 Hook은 실제 분석 후 결정한다.
- 숫자보다 각 편의 구별되는 메시지와 품질을 우선한다.
