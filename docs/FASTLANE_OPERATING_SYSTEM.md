# Shorts Factory 성장 운영 체계

Shorts Factory의 목적은 영상을 많이 저장하는 것이 아니라, 검증된 시청자 문제를 반복 가능한 수익 자산으로 바꾸는 것이다.

## 현재 판단

생산 엔진은 작동한다. 부족한 연료는 조회수가 아니라 다음 두 가지다.

1. 시청자가 다시 찾아오는 이유를 설명할 수 있는 데이터
2. 시청자의 문제 해결 의지가 실제 구매 의사로 이어지는지 보여주는 증거

따라서 새 채널과 새 기능보다 `도달 → 공감 → 재방문 → 소유 고객 → 결제`의 가장 약한 고리를 먼저 개선한다.

## 운영 우선순위

1. 삶의여백 한 채널을 성장 실험의 중심으로 둔다.
2. 일반 숏츠는 문제와 공감을 검증한다.
3. 초단편은 훅과 도달만 실험하며 주 2편을 넘지 않는다.
4. 롱폼은 조회 또는 공감률이 검증된 숏츠만 확장한다.
5. 수익 상품은 요청이나 선주문 신호가 생기기 전에 만들지 않는다.
6. 새 채널은 삶의여백에서 첫 유료 고객과 검증된 주제군을 만든 뒤 검토한다.

## 판단 지표

- 도달: 노출, 계속 시청함, 조회수
- 공감: 좋아요율, 댓글률, 공유, 구독 전환
- 신뢰: 재방문 시청자, 롱폼 시청시간
- 소유: 이메일·알림 신청
- 수익: 구매자 수, 매출, 콘텐츠 운영시간당 매출

조회수만 높은 초단편은 도달 자산이지 수익 증거가 아니다. 반대로 조회수가 중간이어도 댓글·구독·자료 요청이 높은 콘텐츠는 수익 후보가 될 수 있다.

## 첫 수익 검증 순서

1. 관계 문장 자료가 필요한지 질문한다.
2. 명시적인 요청을 모은다.
3. 요청이 확인되면 무료 1페이지 자료로 신청 행동을 측정한다.
4. 요청 20건 또는 선주문 5건 이후에만 4,900~9,900원 상품을 만든다.
5. 첫 구매가 발생하기 전에는 회원제나 대규모 서비스를 개발하지 않는다.

상세 임계값은 `config/growth-operating-system.json`을 단일 기준으로 사용한다.
